# Ledger（coffee-ledger）

岩間・小林・谷の3人で、コーヒーフェス出店の売上・経費・精算を記録するアプリです。
スマホのブラウザで開き、ホーム画面に追加すればアプリのように使えます。

## しくみ

| 役割 | 使っているもの |
| --- | --- |
| 画面（アプリ本体） | HTML / CSS / JavaScript（このフォルダ） |
| 公開 | GitHub Pages |
| データの保存 | Firebase Firestore（東京リージョン） |
| ログイン | Firebase Authentication（Googleログイン） |

## 画面の階層

```
メインメニュー
├── プロジェクト作成   店舗 or イベント名＋日付（イベントのみ）を入れる
├── プロジェクト一覧
│   └── [イベント名]
│       ├── イベント（店舗）詳細   場所・時間・出店料・URL・メモ
│       ├── 在庫・備品（持ち物リスト）  積んだらチェック／「使った数」で在庫が自動で減る
│       ├── 経費・トランザクション・集計
│       └── 精算
├── 在庫     豆・カップなど、数が減っていく物の台帳
├── 備品     テント・ドリッパーなど、くり返し使う物の台帳
└── 屋号情報  屋号・メンバー・関係のあるURL・メモ
```

## Firestoreの中身

| コレクション | 中身 |
| --- | --- |
| `projects` | 店舗・イベント（種類・名前・日付・場所・出店料など） |
| `entries` | 売上・経費の記録（`projectId` でどのプロジェクトの分か分かる） |
| `items` | 在庫・備品の台帳（`kind` が `stock` か `gear`、数 `qty`） |
| `packs` | プロジェクトごとの持ち物リスト（持っていく数・使った数・積んだか） |
| `shop/info` | 屋号情報（メンバーと色・メール、経費の科目など） |
| `presence` | いま開いている人のポインタの位置（同時に操作しているときの表示用） |

## フォルダの中身

```
coffee-ledger/
├── index.html            画面の骨組み
├── css/style.css         見た目

```

## 公開のしかた（GitHub Pages）

1. このフォルダの中身をすべて、GitHubのリポジトリ `coffee-ledger` に置く
2. リポジトリの Settings → Pages で、Branch を `main` / `/ (root)` にして Save
3. 表示されたアドレス（`https://ユーザー名.github.io/coffee-ledger/`）を開く

初回だけ、Firebaseの Authentication → 設定 → 承認済みドメイン に
`ユーザー名.github.io` を追加しておく（しないとGoogleログインが失敗する）。

## メンバーを増やす・変える

- **ログインできる人**：Firebaseの Firestore → ルール で、メールアドレスの一覧に追加して「公開」。
  `firestore.rules` にも同じ内容を書いておくと控えになる。
- **画面に出る名前と色**：アプリの「屋号情報」→編集で、メンバーの名前・色・Googleアカウントのメールを登録する。

## 画面を更新したとき

`sw.js` の `VERSION`（例：`'v1'` → `'v2'`）を1つ上げてからアップロードする。
上げないと、スマホに古い画面が残ることがある。

## 記録データのバックアップ

各プロジェクトの「経費・トランザクション・集計」→「トランザクション」→「CSVをコピー」で、表計算ソフトに貼り付けられる形でコピーできる。
